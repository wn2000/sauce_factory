You'll need to obtain the rom and mp3 music files by yourself.

1. Zip the `paprium.bin` rom into `paprium.zip` and put it at `roms/fbneo/paprium.zip`.

2. Zip all mp3 files into another `paprium.zip` and put it at `roms/fbneo/samples/paprium.zip`.

The mp3 samples are optional. If you skip step 2, the game will still run but without BGM.

You can also use your own mp3 files, just need to keep the file names unchanged.

The roms folder should look like the following after this:

```
roms/
├── fbneo
│   ├── paprium.zip (contains the paprium.bin rom)
│   └── samples
│       └── paprium.zip (optional, contains all .mp3 files)
├── hiscore.dat (zero byte dummy file)
└── md_paprium.zip (zero byte dummy rom)
```
